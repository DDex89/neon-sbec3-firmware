# neon-sbec3-firmware

Разбор прошивки контроллера двигателя Chrysler **SBEC3** (Motorola 68HC16, 1996 год и позже). Цель —
размеченный исходник, который собирается обратно в оригинал, и описания калибровки для редактора
(TunerPro XDF). Основная цель — Dodge / Plymouth Neon 1996+; Mitsubishi Eclipse / Eagle Talon второго
поколения с мотором 420A используют то же семейство блоков и помогают как эталон.

[English version](README.md)

Родственный проект: [neon-fcc-firmware](https://github.com/DDex89/neon-fcc-firmware) — полностью
собранная и размеченная прошивка блока Neon 1995 года (FCC, 68HC11). Большая часть логики управления
SBEC3 и единицы её величин происходят оттуда.

## Состояние

Этап 6 из 6: описания для TunerPro (первая версия, в TunerPro ещё не проверялась). Все одиннадцать образов собираются байт в байт; эталон —
**05293190AC** (Eclipse 1999, механика), выбран потому, что для него есть внешние опорные адреса.
Его разметка автоматически переносится на остальные шесть семейств, и по одному образу на семейство
лежит в репозитории в виде исходника.

| Этап | Содержание | |
|---|---|---|
| 1 | Обзор: образы, раскладка памяти, контрольная сумма, семейства | готово, см. [docs/ru/images.md](docs/ru/images.md) |
| 2 | Инструменты: дизассемблер CPU16, ассемблер, генератор исходника, сборка байт в байт, CI | готово, см. [docs/ru/tools.md](docs/ru/tools.md) |
| 3 | Каркас программы: сброс, прерывания, главный цикл, планировщик, связь | готово, см. [docs/ru/architecture.md](docs/ru/architecture.md) |
| 4 | Калибровка: форматы таблиц, поиск и названия таблиц | готово, см. [docs/ru/calibration.md](docs/ru/calibration.md) и [каталог](docs/catalogue/05293190AC.md) |
| 5 | Подробная разметка, документация на английском и русском, перенос на другие семейства | первый проход готов, см. [docs/ru/porting.md](docs/ru/porting.md); названия продолжаются |
| 6 | Описания для редактора: TunerPro XDF, генерируемые из разметки | первая версия, см. [docs/ru/tunerpro.md](docs/ru/tunerpro.md); нужна проверка в TunerPro |

Что ещё не выяснено, и проверки разметки: [docs/ru/open-questions.md](docs/ru/open-questions.md).
Подпрограмма базового импульса впрыска и что должна сохранить её замена, с покомандным симулятором: [docs/ru/fuel-pulse.md](docs/ru/fuel-pulse.md).
Размеры карт, неиспользуемый код и свободные флеш и ОЗУ у 05293190AC, 05007038 и 04887050/51 как основа для доработок: [docs/ru/revision.md](docs/ru/revision.md).

## Структура

```
docs/en, docs/ru        документация
src/<номер>/            сгенерированный исходник, по файлу на банк 64 КБ; по образу на семейство
annotations/            имена и заметки для генератора: метки, ОЗУ, биты флагов, регистры, векторы, таблицы
annotations/ports/      то же, перенесённое на другие образы через tools/port.py
annotations/hand/       ручные имена для перенесённых образов (05007038, 04887050) там, где перенос оставил пробелы
docs/catalogue/         сгенерированный каталог калибровки каждого образа
docs/diffs/             сгенерированные отличия калибровок внутри семейств
xdf/                    сгенерированные описания для TunerPro, по одному на образ
tools/                  таблица команд CPU16, декодер, ассемблер, анализ, генератор, сборка, обзор
roms/                   место для образов flash (не распространяются, см. roms/README.md)
third_party/            SBECBootLoader Дино Янси: чтение и перепрошивка на стенде
```

## Сборка

```sh
python3 tools/build.py   # собирает src/ и проверяет SHA-256; образ ПЗУ не нужен
```

## Чтение и перепрошивка блока

В `third_party/SBECBootLoader` лежат ядра и скрипты Дино Янси. Они загружают небольшое ядро через
линию SCI в режиме загрузки (напряжение на SCI RX при включении питания), после чего могут читать и
писать flash и EEPROM. Для записи нужно 20 В на SCI RX. Подключение и команды — в его
[README](third_party/SBECBootLoader/README.md).
