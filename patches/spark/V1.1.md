# Spark V1.1 — remove the PT RPM fallback

The original V1 experiment is retained in simulate.py. This variant uses a 30-byte table for the 15 mismatched PT RPM inputs (48..62). All other positions use the shared DinoFuel Q11 index. The exception table stores exact stock Q8 fractions in the same packed layout. Both byte-angle tables, stock interpolation, corrections and scheduling remain unchanged.

Code at $0FD40, exceptions at $0FDE0; both inside the existing Spark reservation ending at $0FE00. No persistent RAM. This is an alternative implementation of the same spark module, not an additional module to stack with V1. All comparisons must remain exact, including the original non-stack RAM writes. Performance is measured on a sample grid, not certified for the complete ISR.

Run `python3 patches/spark/simulate_v11.py 04887050` or add `--full`.
