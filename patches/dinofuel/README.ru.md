# DinoFuel — экспериментальный порт для SBEC3 128 КБ

[English](README.md)

## Назначение

Адаптация исправленного [DinoFuel](https://github.com/DDex89/dinofuel) Дино Янси (dino2gnt) для 04887050 и 05293013AC. Модификация вынесена отдельно от оригинальных исходников. Штатные исходники, XDF и побайтно идентичная сборка сохранены.

Заменяется только поиск топливного значения и расчёт базового импульса. Сохраняются MAP hold, штатное отсечение, TipIn802, CalcFuel432, обогащение WOT, барометрическая компенсация и последующие коррекции. За границами калибровочного диапазона MAP используется штатный алгоритм. Изменение адаптаций при наддуве не переносилось.

## Размещение

| Блок | Адрес | Байт |
|---|---|---:|
| Частичная нагрузка 17 × 17 | $04401 | 615 |
| WOT 9 × 17 | $04669 | 343 |
| Код | $0FC04 | 342 |
| Точка подмены одного JSR | $07DEA / $07E0A | 4 |

Размер образа — 128 КБ. Таблицы содержат удвоенный базовый импульс в беззнаковых 16-битных словах, рассчитанный из калибровки каждого исходного образа. Слова выровнены по чётным адресам; дополнительная постоянная RAM не выделяется. При нулевой дроби устраняется лишнее чтение следующего слова.

## Сборка и тестирование

Из корня репозитория:

```sh
python3 tools/build.py 04887050 05293013AC
python3 patches/dinofuel/dinofuel128.py build/04887050.bin --full
python3 patches/dinofuel/dinofuel128.py build/05293013AC.bin --full
```

Генератор проверяет SHA-256 исходной прошивки, свободные области, точку подмены и контрольную сумму. Расширенный тест охватывает оба состояния флага обогащения WOT, узлы оси RPM, границы MAP, насыщение и отдельные проверки опций MAP hold и TipIn. Это не полный перебор всех возможных комбинаций.
