# DinoFuel V2 — атмосферные SBEC3 128 КБ

[English](README.md)

Основной кандидат — Q11: топливные коэффициенты Q2.14, 512-байтная индексная таблица RPM, неизменная штатная линейная зависимость от MAP. V1 с абсолютными импульсами оставлена отдельно. Поддерживаются только точные оригиналы 04887050 и 05293013AC. Полный прогон прошёл 262 144 комбинации и 3 584 граничных проверки. В рабочих диапазонах максимальная погрешность базового импульса PT/WOT 0,692%/0,468%, средняя 0,11349%/0,08923%. Модельный максимум времени 119,21 мкс, стек 22 байта на проверенной сетке.

В [xdf/](xdf/) находятся определения V2 Q11: 442 ячейки на образ, формула X/16384, нейтральное значение 1,0. **XDF V1 несовместим с V2.** Оси фиксированы. Проверка `check_calibration.py` отклоняет изменения вне топливных ячеек и контрольной суммы, в том числе изменения индекса и осей RPM. Это структурная проверка, не подтверждение безопасной калибровки.

Сборка и тест из корня neon-sbec3-firmware:

```sh
python3 tools/build.py 04887050 05293013AC
python3 patches/dinofuel/v2/check_calibration.py 04887050
python3 patches/dinofuel/v2/check_calibration.py 05293013AC
python3 patches/dinofuel/v2/simulate.py 04887050 --full
```

[Подтверждённый полный прогон](https://github.com/DDex89/neon-sbec3-firmware/actions/runs/45495253939). Реальный TunerPro, полный бюджет ISR, вся цепочка коррекций и физический стенд остаются отдельными этапами. Турбирование отложено: [чек-лист](TURBO_CHECKLIST.md).
