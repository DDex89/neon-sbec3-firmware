# Стендовая проверка штатного SBEC3

Первый проход рассчитан на реальный ЭБУ со штатной прошивкой на изолированном стенде. Прошивку сохраняем, форсунки и катушки оставляем без силовой нагрузки. ROM из архива позволяет проверять инструкции в симуляторе. Стендовые выводы относятся к конкретным плате и прошивке, указанным в записи.

| Какой ЭБУ есть | С чего начать | Что останется открытым |
|---|---|---|
| Точный 05293013AC | Записать время от сброса до первого штатного ответа SCI. Если есть подходящая трассировка, привязать внутренние события к общей шкале времени. | Реакция платы на чтение в ObdFaultAging, пока оно не встретится в штатном прогоне и не будет наблюдаться средствами стенда. |
| Точный 04887050 | Снять тот же базовый прогон. В симуляции вычисленный адрес ObdFaultAging для этого ROM попадает в SRAM. | Физическое поведение 05293013AC. |
| Другой SBEC3 на 128 КБ | Отладить запись на доступном блоке. Перед переносом результатов сверить маркировку MCU, ревизию платы и идентификатор ROM. | Результаты для обеих точных конфигураций. |
| Только 256 КБ или ЭБУ пока нет | Выполнять проверки на точных ROM в симуляторе. | Карта памяти и тайминг 128-КБ плат на стенде. |

## Что сохранить в протоколе

1. Номер блока, ревизию платы, маркировку MCU и идентификатор прошивки. SHA-256 добавляется при наличии точного образа, считанного без записи в ЭБУ. Наклейка корпуса подтверждает только номер на корпусе.
2. Условия включения и сброса, первый доступный штатный ответ SCI, общий источник времени и разрешение записи. Сигналы тактирования или шины записываются только при известной плате и доступных точках наблюдения. Сравниваемые прогоны используют согласованные входы и условия запуска.
3. По внешним сигналам можно измерить время ответа. Для стека, перекрытия IRQ и конкретного обращения к памяти нужна подходящая трасса состояния CPU или шины. Пропуск ответа сам по себе не устанавливает причину.
4. В первом проходе сохраняем штатный ROM, наблюдаем обычный запуск и диагностику. Принудительные обращения к памяти, диагностические записи и перекрёстная прошивка вариантов в этот проход не входят.

Точный ROM подтвердил по 31 значению настройки при сбросе. При этой конфигурации вычисленный адрес 04887050 лежит в SRAM, адрес 05293013AC выходит за окна SRAM и включённых chip select. Тесты с заданным кадром прошли для обработчиков. Ответ реальной платы, фактический момент IRQ и содержимое аппаратного кадра остаются открытыми. [Руководство NXP по M68HC16 Z](https://www.nxp.com/docs/en/data-sheet/MC68HC16ZUM.pdf)

Для ReCore сначала нужна штатная трасса на доступной плате. Владение RAM, стек и совместная работа DinoFuel V2 / Spark V2 остаются отдельными критериями интеграции. Наблюдавшийся максимум глубины стека записывается вместе со сценарием и начальным состоянием.

Для каждого прогона достаточно записать ЭБУ, плату и MCU, ROM и SHA-256, сценарий, входы, начальное состояние, шкалу времени, имя файла записи, выводы и то, что запись не позволяет установить.
