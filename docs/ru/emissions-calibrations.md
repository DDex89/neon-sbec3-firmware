# Заводские экологические варианты и разрешение мониторов OBD

FED обозначает федеральную экологическую спецификацию США, CAL — Калифорнию, CAN — канадскую спецификацию. BUX расшифровывается как Built Up Export и само по себе не определяет страну назначения. MEX обозначает Мексику. В сервисной таблице FCA несколько вариантов могут быть объединены в одну строку, например FED/CAN или FED/CAL. Применяемость уточняется по конкретной строке. [Сокращения Mopar](https://www.moparrepairconnect.com/dA/d1d37f47dc/acronyms-abbreviations.pdf) · [Таблица FCA FedWorld](https://kb.fcawitech.com/assets/FedWorldReport.pdf)

| Номер из заголовка ROM | Подтверждённая применяемость |
|---|---|
| 04887050 | FJ 1996, 2.0 DOHC, автомат, группа FED/Taiwan/CAL. FedWorld, печатная стр. 043. |
| 04887051 | FJ 1996, 2.0 DOHC, механика, группа FED/CAL. FedWorld, стр. 043. |
| 05269833AH / 05269833AI | FJ 1998, 2.0, механика, группа FED/CAL. AH указан среди предшественников AI. FedWorld, стр. 308. |
| 05269834AJ | FJ 1998, 2.0, автомат, группа FED/CAL. FedWorld, стр. 308. Файл, присланный как 05269834AI, в заголовке содержит AJ. |
| 05293148AA | PL Neon 1998–1999, 2.0 SOHC, механика, FED. Указан среди предшественников 05293063AF. FedWorld, стр. 314. В архиве это ROM из файла 05293063AC. |
| 05007038 | Совпадает по номеру с Mopar Performance P5007038 для Neon 1997–1999 DOHC с механикой. На присланной странице каталога 193 указана механическая коробка. Из ROM по $00302 прочитаны номер в BCD 05 00 70 38 и байты ревизии 98 41. |

Строка FED/CAL описывает сервисную группу. Экологическую комплектацию конкретной машины нужно сверять отдельно. Для 05293013AC, 05293014AC, 05293190AC и 05032017AA подтверждённая привязка к рынку в этом проходе не найдена. [Таблица FCA FedWorld](https://kb.fcawitech.com/assets/FedWorldReport.pdf) · [Каталог Mopar Performance](https://starparts.chrysler.com/starlibrary/dto/PerformancePartsCatalog.pdf)

У 05007038 и 05293148AA общий код семейства C и 2 214 различающихся байтов калибровки и других данных. Первый номер относится к Mopar Performance для DOHC, второй — к сервисной группе SOHC FED. По этому сравнению нельзя выделить вклад одного только рынка или одной только спортивной калибровки. [Побайтовое сравнение семейства C](../diffs/05293148AA_05007038.md)

## Проверка разрешения мониторов

Команда `python tools/obd_enablement.py` проверяет SHA-256 каждого ROM, сравнивает таблицу опций с исполнением ObdRecordFlags и проверяет бит 7 при двух начальных состояниях. В таблице указаны строки, которые разрешает эта подпрограмма. Фактическая готовность и завершение монитора зависят от условий работы.

| ROM | Разрешено строк | Результат сравнения |
|---|---:|---|
| 04887050 / 04887051 | 9/13 у каждого | Разрешены те же строки |
| 05293013AC / 05293014AC | 9/13 у каждого | Разрешены те же строки |
| 05007038 / 05293148AA | 11/13 и 9/13 | У 05007038 по $0335 установлены маски $20 для проверки продувки и $02 для насоса обнаружения утечек. У 05293148AA обе строки выключены. |
| 05269833AH / 05269833AI / 05269834AJ | 12/16 у каждого | Разрешены те же строки |
| 05293190AC | 12/16 | Опорный ROM |
| 05032017AA | 0/16 | ObdRecordFlags не разрешает ни одну строку. Другие пути диагностики этим тестом не охвачены. |
