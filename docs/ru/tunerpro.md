# Описания для TunerPro

`xdf/<номер>.xdf` — описание для TunerPro для каждого из одиннадцати образов, сгенерированное из
разметки инструментом `tools/xdf.py`. Откройте в TunerPro нужный `.bin` и выберите XDF с тем же
номером: адреса в семействах разные, а подписи рядов считаются по конкретному образу.

**Состояние: сгенерировано, в TunerPro ещё не проверялось.** Файлы — корректный XML (это проверяет
CI) и следуют раскладке XDF 1.60, которой пользуются другие генераторы, но раскладка 2D-таблиц
(чередующиеся пары x/y, чтение с шагом 16 бит) и нумерация категорий в самой программе ещё не
проверены. Пожалуйста, сообщите, что не открывается или показывает неверные значения.

## Что внутри

| Категория | Содержимое |
|---|---|
| Fuel | `PartThrottleFuel`, `WotFuel` (в % изменения длительности впрыска, посчитанной по MAP), масштабы MAP, `InjectorDeadTime`, `BaroFuel`, `ReturnlessFuelScale`, константы K и смещения MAP |
| Spark | `PartThrottleSpark`, `WotSpark` (градусы), поправки по температуре ОЖ, `KnockThreshold` |
| Idle | `IdleTargetRpm` |
| Sensors | кривые термисторов, замена ДПДЗ при отказе |
| Limits | `RevLimit`, `RevLimitAlt`, ограничитель скорости |
| Faults | `FaultTable`: строка на неисправность, P-код в подписи строки |
| Unidentified | все остальные таблицы, сгруппированные по читающей их подпрограмме, если у неё есть имя |

Набор названных таблиц зависит от семейства (см. [porting.md](porting.md)): 17 таблиц в семействах
D, E и F, 13 в G, 11 в A, B и C. Все таблицы есть в каждом XDF; у неназванных в описании указаны адрес
и входы, а единицы берутся из входов там, где они известны (об/мин, °C, кПа, вольты).

## Оси

- 3D-таблицы с записанной осью столбцов: ось читается из образа и редактируется (обычно обороты).
- Ряды 3D-таблиц не записаны: ряд выбирается таблицей масштаба MAP (`PartThrottleMapScale`,
  `WotMapScale`). XDF подписывает каждый ряд значением MAP, которое его выбирает, посчитанным по
  таблице масштаба **в момент генерации**. Если изменить таблицу масштаба, подписи рядов останутся
  старыми, пока XDF не сгенерировать заново (`python3 tools/xdf.py roms/<номер>.bin xdf/<номер>.xdf`).
- У 3D-таблиц без записанной оси показаны позиции 0-255.
- 2D-таблицы: значения x — редактируемая ось, значения y — столбец данных.

## Единицы

Как в [calibration.md](calibration.md): об/мин = x * 32, кПа = x / 2,428, УОЗ = x / 2 градуса,
°C = x - 128, вольты = x / 16,19 (бортсеть) или x / 51 (детонация), мёртвое время в микросекундах =
x * 32. Топливные таблицы показаны как процент изменения, (x / 256) * 100, со знаком.

## Контрольная сумма

TunerPro не исправляет контрольную сумму SBEC3. После сохранения изменённого образа запустите

```sh
python3 tools/fixsum.py edited.bin --fix
```

Он ставит байт коррекции (заголовок + 13) так, чтобы 8-битная сумма образа снова равнялась последнему
байту номера детали. Без `--fix` только проверяет.
