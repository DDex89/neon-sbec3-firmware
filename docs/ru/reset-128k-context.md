# Reset и контекст исключений A/B (26.11.2026)

Подробности: [английская версия](../en/reset-128k-context.md). $F8002 — UnexpectedEventContextWord0, $F8004 — UnexpectedEventContextWord1. При обычном неожиданном IRQ содержат D и CCR/PK; при исключении — CCR/PK и сырое младшее слово PC. Холодный путь копирует Scratch4/2 соответственно, тёплый пропускает копирование. ResetCheckWord $F8006 сохраняет имя: рабочий байт VSS с дополнением, сумма NvChecksum при выключении, маркер 4AB4/5/6 при сбросе. Пять обращений с именем UnexpectedIrqFlags в O2SwitchState на ROM используют переназначенный Z, а не $F8000; исправление контекстной генерации отдельно. Машинные проверки не запускались.
